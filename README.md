## Как добавить новый тест

1. Сделай тест (например, в ChatGPT) и скачай его файлом `.html`.
2. Открой **claude.ai/code** → новая сессия → выбери репозиторий **kofman-psy/kofman-psy.github.io**.
3. Приложи файл и напиши, например: **«Новый тест, адрес otnosheniya. Опубликуй.»**
   Адрес — латиницей, можно через дефис. Не знаешь, какой, — Claude предложит.
4. Через несколько минут Claude пришлёт ссылку: `https://kofman-psy.github.io/otnosheniya/`.

Claude сам создаст папку под тест, вынесет фото в отдельные файлы, сделает превью для пересылки и кнопку «Поделиться», проверит тест на телефоне и опубликует. Главную и другие тесты он не трогает. Подробная инструкция для него — в файле `CLAUDE.md`.

## Как поправить тест

- **Через Claude:** «В тесте otnosheniya поменяй третий вопрос на …» — он поправит, проверит и опубликует.
- **Сама, мелочь в тексте:** на github.com открой файл `index.html` нужного теста → карандаш **Edit** → поправь → **Commit changes**. Через 1–2 минуты правка на сайте.

Если Телеграм показывает старое превью ссылки — отправь её с хвостом `?2`, например `https://kofman-psy.github.io/?2`.

⚠️ Репозиторий открытый: всё, что в нём лежит, видно всем.
