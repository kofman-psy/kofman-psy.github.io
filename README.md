Этот файл и инструкция для Claude (`CLAUDE.md`) на сайте не видны — только здесь, в репозитории. Но сам репозиторий открытый: всё, что в нём лежит, видно всем.

## Один раз, перед первым тестом

1. **Подписка Claude Pro (или выше)** — в ней есть вкладка **Code**. На бесплатном тарифе её нет.
2. **Приложение Claude** на телефоне (App Store / Google Play) → войти → вкладка **Code**. Или в браузере: claude.ai/code.
3. Claude предложит подключить GitHub → войти как **kofman-psy** → **Authorize**. Попросит установить приложение Claude на GitHub — оно уже стоит, подтверди или нажми **Skip**.
4. **Скрыть почту на GitHub** (иначе правки через сайт GitHub покажут её всем): github.com → аватар → **Settings** → **Emails** → включить **Keep my email addresses private** и **Block command line pushes that expose my email**.

Папки на GitHub создавать не нужно — Claude делает папку сам, вместе с тестом.

## Как добавить новый тест

1. Сделай тест (например, в ChatGPT) и скачай его **файлом `.html`**. Ссылку на ChatGPT Claude открыть не сможет.
2. **Code** → новая сессия → внизу выбери репозиторий **kofman-psy/kofman-psy.github.io**.
3. Режим у поля ввода — **Auto**: в нём Claude работает сам, без вопросов. Если **Auto** в списке нет — **Accept edits**, но тогда Claude будет часто спрашивать разрешение на команды: приложение не закрывай и каждый раз жми **Разрешить**. **Plan** не выбирай — в нём Claude ждёт одобрения плана.
4. Приложи файл и напиши: **«Новый тест, адрес otnosheniya. Опубликуй на сайте.»** Адрес — латиницей, через дефис; не знаешь какой — Claude предложит.
5. В режиме **Auto** можно закрыть приложение — Claude работает сам. Через несколько минут в сессии будет ссылка: `https://kofman-psy.github.io/otnosheniya/`.

**Файл не прикрепляется** (бывает с телефона): открой github.com в браузере → репозиторий **kofman-psy.github.io** → папка **inbox** → **Add file** → **Upload files** → выбери файл → **Commit changes**. Если кнопки **Add file** не видно — включи в браузере «Версия для ПК». Потом в Claude (можно в той же сессии) напиши: «Возьми тест из inbox, адрес otnosheniya. Опубликуй на сайте». Не получается и так — перешли файл Артёму.

Claude сам вынесет фото в отдельные файлы, сделает превью для пересылки и кнопку «Поделиться», проверит тест на телефоне и опубликует. Главную и другие тесты он не трогает. Если найдёт в тесте ошибку, из-за которой результат считается неверно, — сначала спросит.

## Как поправить тест

- **Через Claude (лучше, а с телефона — только так):** «В тесте otnosheniya поменяй третий вопрос на … Опубликуй.» или «На главной поменяй подпись под кнопкой на … Опубликуй.» — поправит, проверит, опубликует.
- **Сама, мелочь в тексте, с компьютера:** на github.com открой `index.html` нужного теста → карандаш **Edit** → найди фразу через Ctrl+F (текст в файле идёт длинными строками) → поправь → **Commit changes**. Меняй только буквы внутри текста — кавычки и знаки вокруг не трогай, одна стёртая кавычка ломает весь тест. После правки открой тест с хвостом `?2` и пройди до конца. Не уверена — через Claude.

Изменения появляются на сайте через 1–2 минуты (иногда до 10). Если Телеграм показывает старое превью ссылки — отправь её с хвостом `?2`, например `https://kofman-psy.github.io/?2`.
