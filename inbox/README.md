# Входящие тесты

Сюда можно загрузить файл теста (`.html`), если он не прикрепляется к сообщению в Claude:
**Add file** → **Upload files** → выбрать файл → **Commit changes**.

Потом в Claude: «Возьми тест из inbox, адрес <адрес>. Опубликуй на сайте».
Claude разместит тест в своей папке и удалит файл отсюда. На сайте эта папка не видна, но в репозитории — видна всем.
